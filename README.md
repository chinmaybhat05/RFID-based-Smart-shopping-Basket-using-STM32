# RFID Smart Shopping Basket (STM32F401RE)

An embedded shopping basket that identifies products using RFID tags, lets the customer log in with a phone number, and sends the final bill by SMS. Firmware runs on an STM32F401RET6 and is written in C using the STM32 HAL.


## Features

- **Product scanning:** MFRC522 (RC522) RFID reader over SPI reads the UID of each product tag
- **User interface:** character LCD for prompts and running total, keypad for input
- **Phone-number login:** the customer enters a mobile number on the keypad
- **SMS billing:** a GSM module sends the itemised bill to that number
- **Debug output:** UID and status messages over USART2 at 115200 baud

## How it works

```
 Scan product tag --> RC522 reads UID --> look up item and price --> add to bill
                                                                        |
 Enter phone number on keypad --> confirm on LCD --> GSM sends bill by SMS
```

1. The MFRC522 driver (`mfrc522.c`) initialises the reader, checks for a card with a REQA request and reads the UID using the anti-collision command.
2. Each UID is matched against a product table to get the item name and price.
3. The LCD shows the item and running total, and the keypad is used to log in and confirm.
4. On checkout the GSM module sends the bill to the entered number with AT commands over UART.

## Build and flash

1. Install [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html).
2. Clone this repository and use **File > Open Projects from File System** to import it.
3. Build with the hammer icon (Debug configuration).
4. Connect an ST-Link and click **Run** or **Debug** to flash.
5. Open a serial terminal on the ST-Link virtual COM port at **115200 8N1** to see debug output.
